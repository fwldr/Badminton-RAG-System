## 五、bad case 清单（expand 关 FAIL 7 题，含根因诊断）

> 每道均用分步诊断脚本复现「检索 top-10 → 过滤条件 → 生成窗口 top-5 → 回答」定位根因。

### 1. q13「推荐一款 YONEX 的球线」0/3，兜底 —— 检索召回偏倚（品牌主导）
top-10 里 **string_specs 只排第 9/10 位**（AEROBITE d=0.337 / EXBOLT65 d=0.339），前 8 条全是 YONEX 球拍（疾光1000PALY 等）与 YONEX 羽毛球（F-90/AS-50 等）的「品牌相似」记录。生成窗口 top-5 无任何球线信息 → LLM 兜底。bge-m3 对「球线」一词的判别被「YONEX」品牌特征淹没。

### 2. q14「李宁有什么羽毛球鞋」0/3，兜底 —— 精排把正确表排到窗口外
检索命中了 shoe_specs（李宁 刀锋MAX/贴地飞行/雷霆PRO 等排第 5-8 位），但 **BGE-Reranker 精排后 top-5 窗口 = 2 球拍 + 3 羽毛球 + 0 球鞋** → LLM 无球鞋信息可答。过滤条件为 `{}`（未抽到品牌过滤）。球鞋行文本长（鞋面/中底/大底）、与「有什么」的问法相关性被精排低估。

### 3. q16「76 和 77 球速有什么区别」1/3，兜底 —— 属性过滤误伤知识源
检索非常健康：speed_grade 四行（75/76/77/78）排第 1-4 位。但 LLM 抽出的过滤条件是 `{"球速": ["76","77"]}`，而 **speed_grade 知识表记录没有「球速」metadata 字段，被 apply_filters 全部过滤掉**；窗口只剩 shuttlecock_specs 产品行（单行含 74-79 多档球速 × 多温度段），LLM 无法给出两档区别 → 兜底。这是「过滤条件把知识源误伤」的链路问题。

### 4. q21「夏天应该选什么速度的羽毛球」0/3，答错（关键词缺失且与知识库矛盾）
回答称「选球速 77，适合高温（25°C 以上）」，引用向羽402 / MASTER NO.6。但这些产品行是**多值字段**：球速「75,76,77」+ 适用温度「中低温/中温/高温」同列并存，无「哪档球速对应哪个温度」的映射。LLM 把「球速77」与「高温」错误关联——而速度等级知识表明明写 **75(慢速)→高温(25°C 以上)、77(中速)→中低温(15-20°C)**。答案不仅缺期望关键词「75」，内容本身与知识库矛盾（faithfulness 风险）。根因：**规格表多值字段 + 生成窗口未突出知识表**。

### 5. q27「哪些因素影响羽毛球耐打度」0/3，关键词缺失 —— 生成完整性不足
回答内容正确、来源正确（引耐打度影响因素/飞行稳定性影响因素）、无编造，但**遗漏了知识表首行因子「毛片韧性」**（耐打性排序：鹅单边＞鹅大刀…），只列了弯曲度/厚度/工艺/温度/使用方式 → 期望关键词「韧性」缺失。属「检索到位、生成漏项」的质量问题，不是检索失败。

### 6. q01「4U和5U球拍有什么区别」1/3，兜底 —— LLM 非确定性
检索与生成窗口正常（诊断时实际答得很好，能对比重量/中杆/磅数差异）。对比类问题偶发「不足以回答」兜底：同一候选池、同一窗口，DeepSeek 对「单条上下文能否支撑对比」的判断不稳定。

### 7. q09「拉吊突击战术怎么打」0/3，兜底 —— LLM 非确定性
检索第 1 位就是「拉吊突击（单打）」、生成窗口 top-5 全是正确战术行（诊断时回答优秀），但 3/3 次兜底。检索与窗口无任何问题，纯 LLM 判定不稳定（expand 开时 2/3 通过，进一步佐证）。

> 另：q11（初学者球鞋，负例）在 expand 关 PASS（3/3 正确兜底），expand 开时有一次**幻觉**——列出一串「适合初学者」的球拍清单而非兜底（2/3，负例要求全过故 FAIL）。负例偶发幻觉是值得警惕的非确定性问题。

## 六、改进建议（按性价比排序）

1. **过滤字段白名单化**（修复 q16）：`apply_filters` 对知识表记录缺失目标属性字段时不应整表丢弃，或对「问题本身是知识问题」时跳过属性过滤。
2. **提示词补充「可回答性」引导**（缓解 q01/q09/q11 非确定性）：上下文中含目标信息时优先尝试回答，不要轻易兜底；负例幻觉需更严格约束。
3. **多值字段拆分或提示词强调映射**（修复 q21）：规格表「球速×温度」多值并列易误导 LLM，可要求回答时优先引用速度等级知识表。
4. **生成窗口跨表保底**（修复 q13/q14）：top-5 前先按「问题词与表主题」做类别粗筛，避免品牌相似的非目标表占满窗口。
5. **faithfulness 追责**：目标 ≥0.8 未达成（0.7044），以上 1-3 项修复后复测。
